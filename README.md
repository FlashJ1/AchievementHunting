# AchievementHunting

This app was created as assistent during Steam Achieve Hunting. There are some features it's like Game List, Max Percent Game and Random Game. In List game has detailed description about the game (Percent and Achievements). Also when you selected game by List Games, you can see unachieved achieves by pressing the unachieved achieve button and launch the game by Launch button. When you achieve this one press Refresh button to refresh your stats (OMG!) Max Percent Button select the highest percent non-Perfect game. Random button select random game (Obviously)
